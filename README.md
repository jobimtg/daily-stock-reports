# Daily Stock Reports

Daily TSX and TAIEX market briefs, generated by Claude.

**Live site:** https://jobimtg.github.io/daily-stock-reports/

## Coverage
- TSX (Toronto Stock Exchange) — index, top movers, sector flows
- TAIEX (Taiwan Stock Exchange) — index, top movers, COMPUTEX news
- TAIEX ETFs — 0050, 0056, 00878
- Notable market news and events

## Format
PDF reports stored in `/reports/`, named `market_data_brief_YYYYMMDD.pdf`.
The home page auto-lists all reports — no manual updates needed.

## Currency
All amounts in CAD (Vancouver, Pacific Time).
